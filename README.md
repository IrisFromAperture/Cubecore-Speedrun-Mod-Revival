# Cubecore-Speedrun-Mod-Revival
I was poking around the files of Krzyhau's Speedrun Mod with the intentions of figuring out how it worked so I could make my own mod. While looking through, I found what looks to be a scrapped gamemode called "Save the Cube", where the player takes a cubical personality sphere dubbed "cubecore" from the start of the game to the end. Recently I've been working on reworking the script to fix bugs, features, and probably add other features in the future. Currently this is just a personal project to get used to writing Vscripts for my own mod in the future, but maybe when I'm done I'll send it to Krzy or someone, but otherwise the only reason I'm working on this is for experience and because the Cubecore model looks cool.

# Downloading
It is currently very unfinished so I'll only be releasing a beta, and I'll make an actual release when I'm happy with my progress.

1. Already have downloaded and installed Krzyhau's Speedrun Mod, for this I recommend making a copy of the files and placing them in a safe space
2. Download all of the files [CHANGE WHEN I MAKE AN ACTUAL BETA RELEASE LOL]
3. place `extras.txt` in `Portal 2 Speedrun Mod/scripts`
4. place `speedrunmod.nut` in `Portal 2 Speedrun Mod/scripts/vscripts`
5. place `cubecore.nut` in `Portal 2 Speedrun Mod/scripts/vscripts/modes`

`extras.txt` and `speedrunmod.nut` make it so that the mod appears on the menu and is selectable, and of course `cubecore.nut` contains all the functions that make the mod work
